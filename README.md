# Harness Engineering 五讲 · 中文课件

基于开源课程 [Learn Harness Engineering](https://github.com/walkinglabs/learn-harness-engineering)（walkinglabs，MIT 协议）做的非官方中文视频课程配套课件。第 1 讲讲透什么是 harness engineering，后面四讲用同一套框架（指令、工具、环境、状态、反馈五个子系统）逐个拆解四个前沿 harness。

每一讲的目录里有：

- `README.md`：这一讲的课件正文，点进目录就能直接读。
- `images/`：正文配图，也就是视频里每块内容讲完时的完整画面。
- `lNN-幻灯片.pdf`：所有配图按顺序合成的一份 PDF，方便下载、打印或边看视频边翻。
